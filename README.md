# 🌍 AI Trip Planner

An **AI-powered autonomous travel assistant** built with **LangChain, LangGraph, and LLMs** that helps users plan personalized trips.  
The system integrates **real-time APIs (flights, hotels, weather)** and uses **RAG (Retrieval-Augmented Generation)** with a vector database to generate optimized itineraries.

---

## 🚀 Features
- 🗨️ **Conversational AI** – plan trips using natural language.  
- 📅 **Personalized Itineraries** – day-by-day schedules.  
- ✈️ **Flights API Integration** – fetch real-time flight data.  
- 🏨 **Hotels API Integration** – suggest hotel options.  
- 🌦️ **Weather API Integration** – forecast-based activity planning.  
- 📖 **Knowledge Base (RAG)** – destination tips, POIs, seasonality info.  
- 📊 **Export Options** – download itinerary as PDF/CSV.  
- 🖥️ **Interactive UI** – built using Streamlit/Gradio.  

---

## 🛠️ Tech Stack
- **Backend**: Python, Flask/FastAPI  
- **LLM Framework**: LangChain + LangGraph  
- **Vector DB**: Chroma / FAISS  
- **Frontend**: Streamlit / Gradio  
- **APIs**:  
  - Flights → Amadeus / Skyscanner  
  - Hotels → Booking.com / Amadeus  
  - Weather → OpenWeatherMap
